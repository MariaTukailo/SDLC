# Использование Spring Boot для серверной части

## Контекст и постановка задачи
Приложению необходима серверная часть, которая будет обрабатывать HTTP-запросы, выполнять бизнес-логику и работать с базой данных PostgreSQL. На каком стеке реализовать Backend?

## Драйверы решения
* **Безопасность:** Встроенная защита (Spring Security).
* **Интеграция с БД:** Удобная работа с PostgreSQL через JPA.
* **Опыт команды:** Наличие опыта разработки на Java.

## Рассмотренные варианты
* Java + Spring Boot
* Node.js + Express
* Python + Django

## Итог решения
Выбран вариант **«Java + Spring Boot»**, потому что фреймворк предоставляет готовые модули безопасности, работы с БД и веб-сервера.

### Последствия
* **Хорошо:** строгая типизация снижает количество ошибок.
* **Плохо:** большее потребление оперативной памяти.

### Подтверждение
Проверка наличия зависимостей `spring-boot-starter-web` и `spring-boot-starter-security` в `pom.xml`.

## Плюсы и минусы вариантов
### Java + Spring Boot
* **Хорошо:** встроенные модули безопасности и БД.
* **Плохо:** высокое потребление памяти.

### Node.js + Express
* **Хорошо:** низкое потребление памяти.
* **Плохо:** нет строгой типизации.

### Python + Django
* **Хорошо:** быстрая разработка.
* **Плохо:** ниже производительность при нагрузках.
